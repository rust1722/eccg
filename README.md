# eccg — Arena + GitHub + Godot 4

Связка работает так:

```
Ты пишешь задачу в Arena
        ↓
Arena (я) создаю/редактирую файлы прямо в этом репозитории
        ↓  git push в ветку arena/58a64d59-eccg
GitHub: github.com/rust1722/eccg
        ↓  ты делаешь git pull
Твой компьютер → открываешь проект в Godot 4 → F5 (Play)
```

Arena не пушит напрямую в твой Godot на диске — мостом служит GitHub.
Поэтому после каждого моего «готово, запушил» тебе нужно подтянуть изменения.

---

## 1. Первый раз: скачать проект себе

Нужны: [Godot 4.x](https://godotengine.org/download) и [Git](https://git-scm.com/downloads)
(или [GitHub Desktop](https://desktop.github.com/)).

В терминале, в папке где хочешь держать проект:

```bash
git clone https://github.com/rust1722/eccg.git
cd eccg
git checkout arena/58a64d59-eccg
git pull
```

> ⚠️ Именно ветка `arena/58a64d59-eccg` — на ней работает эта сессия Arena.
> На `main` пока только начальный коммит.

Затем:

1. Открой Godot 4 → **Import** → выбери файл `project.godot` в папке `eccg`.
2. Дождись импорта, открой сцену `scenes/main.tscn`.
3. Нажми **F5 / ▶ Play** — должен появиться текст
   `Hello from Arena + GitHub + Godot!`, а в консоли:
   `eccg: started. Arena + GitHub + Godot sync works!`

## 2. Каждый следующий раз: получить мои правки

Когда я говорю «запушил в GitHub»:

```bash
cd eccg
git pull
```

Потом вернись в Godot — он сам увидит изменённые файлы
(если спросит про reload / перегрузку сцены — жми **Reload**).

Если ты сам что-то подредактировал в Godot и не хочешь терять,
скажи об этом до `git pull`, иначе возможен конфликт. Я помогу разрулить.

## 3. Как мы работаем дальше

Просто пиши в Arena обычным языком, например:

- «Сделай, чтобы игрок двигался стрелками / WASD»
- «Добавь врага, который ходит туда-сюда»
- «Сделай главное меню и счёт»

Я буду:

1. Создавать/править `scenes/*.tscn`, `scripts/*.gd`, `assets/*` и т.д.
2. Коммитить и пушить в ветку `arena/58a64d59-eccg`.
3. Писать тебе: что изменил + «сделай `git pull` и нажми F5».

Ты в ответ: что видишь в Godot, скриншоты, ошибки из консоли.

## 4. Структура проекта

```
project.godot      — настройки проекта Godot 4
scenes/main.tscn   — главная сцена (запускается по F5)
scripts/main.gd    — её скрипт
assets/            — сюда кладём картинки, звуки и т.д.
icon.svg           — иконка проекта
```

## 5. Чего НЕ надо коммитить

Папка `.godot/` (кэш импорта Godot) уже в `.gitignore` — она создаётся
локально у каждого. В GitHub лежат только исходники, поэтому проект
открывается с нуля на любом компьютере.
