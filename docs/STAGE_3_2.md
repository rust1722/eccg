# Правка этапа 3 — один общий веер на всю таверну

Решение автора от 25.10.2026, отменяет «свою руку у каждой комнаты» (A+).

## Что изменилось

- **Веер один на все комнаты.** В какой комнате вы ни были, внизу одни и те
  же карты. При переходе между комнатами меняется только сцена комнаты:
  нижняя панель (профиль, веер, колода, указатель) вообще не дёргается.
  Анимация «старый веер вниз — новый снизу» при смене комнаты убрана;
  веер выезжает снизу только один раз, при старте игры.
- Зачем: в саду можно собрать карты для алхимии/библиотеки — и просто
  унести их в веере. Раньше они «оставались» в веере сада.
- Архив работает как раньше и стал ещё важнее: ненужное — кликом в Архив,
  нужное — кликом из Архива в веер (карты по-прежнему летают).
- Стартовый веер теперь один общий: Семена подсолнуха, Вода, Лесной суп,
  Зелье лечения. Остальные тестовые карты лежат в Архиве.
- Количество карт в Архиве («×N») теперь в **правом верхнем углу** карты,
  рядом с типом, а не плашкой поверх.

В коде: `InventoryManager.current_hand` вместо `room_hands`,
сигнал `hand_changed` вместо `room_hand_changed`, `HandUI.show_hand()`
вместо показа руки комнаты. Формат будущих сохранений: `hand_ids`
вместо `room_hand_ids` (сохранений пока нет, ломать нечего).

## Как проверить (3 минуты)

1. В GitHub Desktop: **Fetch origin → Pull**.
2. Открой проект в Godot (если спросит про сцену — **Reload**), нажми **F5**.
3. На старте веер выедет один раз: Семена, Вода, Суп, Зелье.
4. Походи по комнатам указателем (Сад, Алхимия, Кухня...): **веер не
   меняется и не перезаезжает** — карты всё те же, панель статична.
5. Открой Архив в любой комнате: в правом верхнем углу каждой карты
   должно быть «×N». Кликни, например, Мясо — оно прилетит в общий веер.
6. С этим Мясом перейди в другую комнату — Мясо осталось в веере.
   Кликни его в веере при открытом Архиве — улетит обратно.
7. В панели **Output** не должно быть красных ошибок; в начале будет
   строка `[Seed] shared hand: ...`.

Пришли скрин, если что-то ведёт себя не так.

## Что осталось как было

- Панель Архива открывается из любой комнаты и теперь даже не закрывается
  при смене комнаты: вееру всё равно, какая комната за панелью.
- Лимит веера 10, добыча при полном веере уходит в Архив (§6.5).
- После проверки Godot может создать `.uid` для изменённых скриптов —
  как обычно, закоммитить и запушить («Файлы Godot после правки веера»).
