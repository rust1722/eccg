# Этап 4 — Сад: первая настоящая механика

Что сделано. Сад перестал быть заглушкой: в нём можно сажать, поливать,
ждать и собирать урожай. Всё кликами (перетаскивание — позже).

## Что появилось

```
scripts/autoload/GardenManager.gd   горшки и таймеры (живут вне сцены)
scripts/rooms/GardenRoom.gd         комната Сада: горшки, статусы, подсказки
scripts/ui/PotView.gd              один горшок: состояние, таймер, клик
resources/cards/test_set/card_sunflower.tres   урожай: Подсолнух
```

Изменения в существующем:

- `SeedCardData` семян подсолнуха теперь знает свой урожай
  (`harvest_result_card` = Подсолнух) и растёт **30 секунд** —
  специально коротко для проверки; настоящие минуты вернём балансом.
- В веере клик по карте (когда Архив закрыт) теперь **выбирает** её:
  золотая рамка. Второй клик по ней же — снять выбор. При смене
  комнаты выбор сбрасывается.
- `InventoryManager.remove_card_from_hand()` — забрать карту из веера
  без возврата в Архив (посадка/крафт/использование).
- На дощечке «Сад» появляется **«!»**, когда что-то созрело.

## Как играть в сад

1. Клик по карте **Семена подсолнуха** в веере — карта подсветилась.
2. Клик по пустому горшку — росток посажен, семя ушло из веера.
3. Клик по карте **Вода** в веере, клик по ростку — таймер пошёл (0:30).
4. Можно уходить в другие комнаты: растение растёт само
   (таймер — в GardenManager, сцена сада для этого не нужна).
5. Горшок стал золотым «Созрело» — клик по нему: **Подсолнух** падает
   в веер, а если веер полон — в Архив. На указателе при этом «Сад !».

## Как проверить (3 минуты)

1. В GitHub Desktop: **Fetch origin → Pull**.
2. Открой проект в Godot (если спросит про сцену — **Reload**), нажми **F5**.
3. Дощечкой **Сад** перейди в сад: 8 горшков, справа подсказка.
4. Кликни семя в веере (золотая рамка), кликни горшок — посажено.
5. Кликни воду в веере, кликни тот же горшок — таймер 0:30 пошёл.
6. Уйди в Бар на полминуты и вернись: горшок должен быть золотым
   «Созрело», а на дощечке — «Сад !».
7. Клик по горшку — Подсолнух в веере. В Архиве он теперь тоже виден
   (был ×0 как «ещё не выращен»).
8. В панели **Output** не должно быть красных ошибок.

Пришли скрин сада (или Output с ошибками, если что-то красное).

## Что осознанно пока просто

- Взаимодействие кликами: «выбрал карту — кликнул объект».
  Перетаскивание (drag-and-drop) прикрутим отдельным этапом на готовые
  механики, когда будет ясно, что таскать приятнее, чем кликать.
- Горшков 8 и все одинаковые; полив только картой «Вода».
- Состояние сада не сохраняется при закрытии игры: сейвов ещё нет,
  таймеры и горшки живут до конца запуска. Сохранение — по §6.6 позже,
  deadline-таймеры к нему готовы.
- Рост 30 секунд — тестовый, не баланс.
- После проверки Godot создаст служебные `.uid` для новых скриптов —
  как обычно, закоммитить и запушить («Файлы Godot после этапа 4»),
  проверив, что в `project.godot` уже **5 Autoload**: Inventory,
  GameState, Player, Room, Garden.
