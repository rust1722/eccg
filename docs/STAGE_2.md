# Этап 2 — оболочка таверны, указатель и веер карт

Что сделано по утверждённой схеме из `docs/DESIGN.md` §6 (вариант D, A+).
Настоящего арта и механик комнат пока нет — комнаты-заглушки, но вся
навигация и анимация веера уже настоящие.

## Что появилось

```
scripts/autoload/
  RoomManager.gd     переходы: старый веер вниз -> смена комнаты -> новый веер снизу
  PlayerManager.gd   золото 142, HP 28/30, уровень 4 (для профиля)

scripts/ui/
  HandUI.gd          веер карт текущей комнаты + анимация смены веера
  CardView.gd        одна видимая карта в веере (название, тип, цены)
  SignpostNav.gd     дорожный указатель с вороной: дощечки комнат
  ProfileUI.gd       профиль в левом нижнем углу

scripts/rooms/
  PlaceholderRoom.gd шаблон комнаты-заглушки

scenes/
  main.tscn          оболочка: RoomSlot + нижняя полоса (профиль, веер, колода, указатель)
  rooms/BarScene.tscn, rooms/GardenScene.tscn
```

Остальные 7 комнат уже видны на указателе, но выключены с пометкой «скоро».

## Как проверить (3 минуты)

1. В GitHub Desktop: **Fetch origin → Pull**.
2. Открой проект в Godot (если спросит про сцену — **Reload**), нажми **F5**.
3. Что должно произойти:
   - Открылся **Бар**. Снизу вылез веер из 2 карт: Лесной суп и Зелье лечения.
   - Слева внизу профиль: Ведьмочка, HP 28/30, Золото: 142, LV 4.
   - Справа внизу указатель с вороной, и **все дощечки комнат видны сразу**:
     слева Бар/Сад/Лавка/Кабинет/Архив, справа отдельным столбцом мастерские.
     Никакого раскрывающегося списка.
4. Сразу жми дощечку **Сад** (один клик).
   - Веер бара уедет вниз, комната сменится на Сад, снизу вылезет новый веер:
     Семена подсолнуха, Вода, Зелень.
   - Ворона скажет «Кар! Сад», дощечка Сада подсветится.
5. Дощечкой **Бар** вернись обратно — в веере снова суп и зелье.
   Это и есть память рук A+: карты бара никуда не девались.
6. В панели **Output** должны быть строки вида
   `[RoomManager] go_to_room: 'bar' -> 'garden'`, `[Stage2] seeded: ...`
   и не должно быть красных ошибок.

Пришли скрин игры (или Output с ошибками, если что-то красное).
