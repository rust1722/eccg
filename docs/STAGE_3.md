# Этап 3 — окно Архива и все комнаты

Что сделано. Арта и настоящих механик комнат пока нет, но теперь игрой
можно «пользоваться»: ходить по всем комнатам и свободно перекладывать
карты между Архивом и рукой любой комнаты.

## Что появилось

```
scripts/ui/ArchiveOverlay.gd   окно Архива поверх комнаты
scenes/rooms/                  ещё 7 комнат-заглушек:
  KitchenScene, ForgeScene, AlchemyScene, LibraryScene,
  ShopScene, CabinetScene, ArchiveScene
```

Изменения в существующем:

- `RoomManager` знает сцены всех 9 комнат — пометок «скоро» на указателе
  больше нет, каждая дощечка кликабельна.
- Кнопка «Колода / Архив» в нижней полосе ожила и открывает окно Архива.
- `InventoryManager.get_known_cards()` — список всех карт для сетки Архива.

## Как устроено окно Архива

- Открывается кнопкой «Колода / Архив», закрывается кнопкой «Закрыть»
  или клавишей Esc.
- Слева сетка всех карт: название, тип, сколько лежит в Архиве (×N).
  Карты с ×0 видны, но выключены.
- Справа рука текущей комнаты и её заполненность, например «Рука: Сад (3/10)».
- **Клик по карте слева** — карта уходит в руку этой комнаты.
- **Клик по карте справа** — карта возвращается в Архив.
- Кнопка «Собрать всё в Архив» возвращает всю руку комнаты одним кликом.
- Если рука полна (10/10), окно честно скажет об этом внизу вместо взятия.

После закрытия окна веер внизу **заново выезжает с новой рукой**, если
состав менялся, — смена руки видна, а не подменяется втихую (§6.5.1).

## Как проверить (4 минуты)

1. В GitHub Desktop: **Fetch origin → Pull**.
2. Открой проект в Godot (если спросит про сцену — **Reload**), нажми **F5**.
3. Походи по указателю: теперь открываются **все 9 комнат**, включая
   мастерские. У каждой своя рука (в основном пустая — это нормально,
   снизу выезжает плашка «В этой комнате рука пуста»).
4. В любой комнате нажми **«Колода / Архив»**:
   - слева будут все 8 тестовых карт с количествами;
   - справа — рука текущей комнаты.
5. Кликни слева, например, **Воду** — она появится справа в руке.
   Кликни её справа — вернётся в Архив, счётчик ×N вырастет на 1.
6. Нажми «Собрать всё в Архив», закрой окно — снизу выедет пустой веер
   (или плашка пустой руки).
7. Снова открой Архив, набери в руку пару карт, закрой — веер выедет
   уже с этими картами.
8. В панели **Output** не должно быть красных ошибок; будут строки
   `[Archive] opened over room: ...`.

Пришли скрин окна Архива (или Output с ошибками, если что-то красное).
